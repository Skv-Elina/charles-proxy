# 🍶 Charles Proxy
Практическая работа по перехвату, анализу и модификации HTTP/HTTPS-трафика.<br>
Все действия с Charles Proxy и браузером записаны на видео.

### 🖥 Работа на настольном компьютере

- изменение количества товаров в запросе к интернет-магазину;
- моделирование ответа сервера с HTTP status code 403;
- перенаправление запросов с production-окружения на stage-окружение.

### 📱 Работа с мобильным устройством

Задания выполнялись с использованием Android Emulator, а не физического смартфона.

- изменение параметров запроса на удаление товара из корзины;
- проверка изменения поведения приложения при модификации запроса;
- подмена изображения, возвращаемого сервером;
- перехват HTTPS-запроса с мобильного устройства;
